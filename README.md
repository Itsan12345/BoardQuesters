
# BoardQuest: Gamified AI-Assisted Board Review System

BoardQuest is a specialized MVP designed for 4th-year Medical Technology students preparing for their Licensure Examination. It focuses on the six major laboratory science areas:
1. Clinical Chemistry
2. Hematology
3. Microbiology
4. Immunohematology
5. Clinical Microscopy
6. Histopathology & MT Laws

## Key Modules
- **Student Dashboard**: Visualizes mastery, XP, streaks, and ranking.
- **Learning Quest**: Spaced repetition practice powered by AI situational questions.
- **Mock Exam Engine**: Timed, high-stakes adaptive examination.
- **AI Tutor Review**: Personalized feedback with logical reasoning for every answer.

## Tech Stack
- **Frontend**: React (NextJS App Router), Tailwind CSS, Shadcn UI.
- **AI Engine**: Genkit with Google Gemini.
- **Backend Architecture**: Structured for Laravel/MongoDB integration.

## Assets
- Static images are stored in `public/images/`.
- Image metadata and placeholders are managed in `src/app/lib/placeholder-images.json`.
